# A fix-like commit

## Question
Your commit "{commit_message}" ({commit_short}) looks like a fix. What was going wrong, and how did you notice it?

## Follow-up
What would stop the same kind of bug from coming back?

## Good answer mentions
- the symptom and the actual cause
- how the bug was found (test, error, reasoning)
- a test or check that guards against regression
