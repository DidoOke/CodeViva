# Test coverage and verification strategy

## Question
At {file}:{line} you wrote `{name}`. What specific behaviour or failure mode does `{name}` verify, and what edge case is still not covered by it?

## Follow-up
If you needed to break your implementation while keeping `{name}` passing, what input would expose the gap?

## Good answer mentions
- the target behaviour and assertions inside the test
- why that scenario matters for correctness
- an additional edge case or property that would strengthen the test suite
