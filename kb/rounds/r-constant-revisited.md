# A value chosen last round was changed this round

## Question
Since last round you changed `{name}` from {old} to {new}. What did you learn that made the old value wrong for this round?

## Follow-up
What would tell you that the new value is wrong too?

## Good answer mentions
- a concrete trigger: a new requirement, a measurement, a failing test
- consistent with, or an honest correction of, what was said last round
- what the new value costs, not only what it gains
